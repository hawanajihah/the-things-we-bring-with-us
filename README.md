# THE THINGS WE BRING WITH US

Instead of being boring and using Powerpoint, I made an interactive backdrop application. 

### Features to be implemented

1. When the website is open, it shows a backdrop of a bedroom with a few posters. 
2. Toggling the keybind F allows me to toggle in and out of full screen mode. 
3. The keybind S shows an automatic photo scroll as an overlay. It consists of old photos of Norman (essentially Gaston). Clicking S again will toggle off the scroll. 
4. When the keybind P is clicked, two parts of a photograph will emerge. The idea was to show the audience visually what happened during the phone call (which was the friend group splitting). At first, it shows only one torn part of the photo, with the other snippet being hidden. Clicking P again shows both. Clicking it again makes the whole photo disappear. 
5. I can also toggle the brightness of the overall application using the keybinds D (to darken the screen), and B (to brighten the screen). Technically, I can use the MacBook HUD Brightness buttons but then you’ll see the overlay which I didn’t want, since it reduces the immersiveness. 
6. When the T key is pressed, the letter from Younger Norman will pan from the bottom. Pressing T will close up the letter and drop down. 
7. Toggling the keybind Q shows the QR code to our programme booklet.
